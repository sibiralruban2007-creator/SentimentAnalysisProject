# Online Product Review Sentiment Analysis Using Machine Learning

## Project Overview
This project performs sentiment analysis on online product reviews using Machine Learning and Natural Language Processing (NLP) techniques. The system classifies customer reviews into three categories:

- Positive
- Negative
- Neutral

The project helps understand customer opinions and feedback automatically from review data.

---

## Objectives
- Analyze customer product reviews
- Clean and preprocess textual data
- Visualize sentiment distribution
- Train a Machine Learning model for sentiment prediction
- Predict sentiment from new reviews

## Dataset Information
The dataset contains product reviews and sentiment labels.

### Dataset Columns
| Column Name | Description |
|---|---|
| ID | Unique identifier |
| Topic | Product/Game topic |
| Sentiment | Review sentiment |
| Review | Customer review text |

---

## Data Preprocessing
The following preprocessing steps were performed:

- Removed missing values
- Removed duplicate data
- Converted text to lowercase
- Removed special characters
- Removed stopwords
- Cleaned review text
